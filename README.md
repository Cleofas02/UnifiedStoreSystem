# 🛒 Unified Store System

A web-based canteen system built using **React**, **Tailwind CSS**, and **Firebase**. This project was developed as a final requirement for Practical Research in school.


## 🛠️ Tech Stack

- React
- Tailwind CSS
- Firebase (Firestore + Hosting)
- JavaScript
- Vite

## 📌 Features

- User-friendly interface for canteen transactions
- Real-time data using Firebase
- Fully responsive layout with Tailwind CSS
- Data storage and retrieval using Firestore
- Modern frontend architecture with React
